# AI 工具檢索庫與職能落地指南 (AI Tools Navigator)

> **AI效能實驗室－秉軒老師**
> 是你，讓 AI 更強大 ｜ You Make AI Stronger.

本專案根據 711 份實戰教學簡報精選整理，涵蓋 48 款核心 AI 工具，專為學員、企業主與各行各業工作者打造的「隨選隨用 AI 導航與職能落地建議指南」。

---

## 🌟 核心功能

1. **🔍 48 款核心 AI 工具檢索庫**
   - 9 大分類即時過濾（文字思考、AI 搜尋、簡報文檔、圖像美編、影音虛擬人、語音音樂、知識庫筆記、思維導圖、自動化開發）。
   - 收費模式切換（完全免費、免費可用、付費訂閱）。
   - **直達官網按鈕**：點擊右上角按鈕即可在新視窗直接開啟官方網站。
   - **實戰提示詞折疊區**：內建簡報傳授的 Prompt 公式，支援一鍵複製。

2. **🎯 職能專屬 AI 行動建議報告產生器**
   - 輸入工作職位（如：人資主管、社群行銷、行政助理、業務經理、高中老師、長照督導、求職新鮮人...）或自訂職稱。
   - 即時生成專屬行動建議報告，包含：
     - **推薦工具組合 (Toolstack)**（附直達連結）
     - **3 階段職能任務落地行動清單 (Action Plan)**
     - **精選實戰指令範本 (Ready-to-use Prompts)**（含一鍵複製）
     - **常見迷思與誤區 (Common Myths)**
     - **易錯提醒與防護線 (Pitfalls & Security)**
   - 支援 **一鍵複製 Markdown 完整報告** 與 **列印 / 存為 PDF**。

3. **⚡ 簡報精選四大高頻實戰工作流**
   - 爆款短影音高效產製工作流
   - 教案教材轉極速視覺簡報工作流
   - 打造企業 24hr「AI 虛擬行銷副總」
   - 個人品牌全自動化客服與導流轉化漏斗

## 🚀 部署說明 (GitHub + Vercel)

本專案為標準靜態 Web 應用程式，無需複雜 Node.js 建置過程，相容於所有現代瀏覽器與靜態託管平台。

### Vercel 一鍵部署
1. 將本專案推送到 GitHub。
2. 前往 [Vercel 儀表板](https://vercel.com/new)。
3. 點選 **Add New Project**，匯入此 GitHub 倉庫。
4. Framework Preset 選擇 **Other**，Build Command 保留空白，Output Directory 設為根目錄 `./`。
5. 點擊 **Deploy**，約 15 秒內即可完成全球 CDN 發布並獲得專屬網址！
